# 《已讀不回：凌晨 23:47》

一款以戀愛關係與出軌疑雲為主題的互動推理遊戲。玩家需要透過聊天紀錄、照片線索、行程紀錄與嫌疑人盤問，逐步拼湊事件真相，最後提出自己的指控。

## 遊戲資訊

- **作品名稱：** 已讀不回：凌晨 23:47
- **作品類型：** 互動推理／懸疑文字遊戲
- **開發方式：** Vibe Coding，透過 AI 協助規劃、生成、修改與測試程式
- **使用技術：** HTML、CSS、JavaScript
- **作品形式：** 單一 `index.html` 網頁
- **線上遊玩：** https://PCCC-Pc.github.io/after-hours-game/

## 故事背景

晚上 23:47，你突然收到一張照片。照片裡的人似乎是你的男朋友林予安，而地點竟然是酒吧「白夜」。

他明明表示自己正在公司加班，照片卻讓一切變得可疑。

照片中的人真的是他嗎？付款紀錄能證明什麼？同事的訊息又隱藏了哪些資訊？

你必須親自調查，從不同來源蒐集證據、詢問相關人物，並判斷哪些線索可信、哪些仍然只是猜測。

## 遊戲玩法

1. **閱讀案件簡報：** 了解事件背景與調查目標。
2. **查看聊天紀錄：** 從人物對話中尋找時間與說法上的疑點。
3. **調查相簿線索：** 觀察照片中的環境、收據與反射影像。
4. **檢視行程紀錄：** 比對門禁、交通及付款等資訊。
5. **盤問嫌疑人：** 查看不同人物對事件的回應。
6. **整理證據：** 蒐集線索，建立自己的推理。
7. **提出指控：** 選擇你認為最可疑的人物，提交證據並查看調查結果。

## 推理攻略與提示

### 建議調查順序

建議先完整閱讀聊天紀錄，再檢查照片與行程紀錄，最後盤問嫌疑人。不要只因為某個人看起來可疑，就直接認定對方是犯人。

### 關鍵線索

- **酒吧照片：** 注意拍攝時間與人物身分是否已經獲得確認。
- **飲料收據：** 兩杯飲料可能代表什麼？付款資訊又能證明到什麼程度？
- **門禁紀錄：** 有進入紀錄，不代表已經知道當事人何時離開。
- **計程車紀錄：** 行程資訊可以提供時間與地點線索，但不一定能直接證明乘客身分。
- **同事訊息：** 留意人物說法是否一致，以及訊息究竟能證明什麼。
- **付款紀錄：** 末四碼相同不一定足以確認付款者身分，仍需要其他線索交叉比對。

### 推理原則

1. 區分「已確認的事實」與「尚未證實的猜測」。
2. 比對不同紀錄的時間是否合理。
3. 不要把單一線索當成完整證明。
4. 提出指控前，先蒐集足夠證據並檢查人物說法。

> 提示：本遊戲的核心是交叉比對線索，而不是只靠直覺猜測。實際結局依遊戲中的指控與證據判定為準。

## 互動功能

- 案件簡報與調查流程切換
- 聊天紀錄、照片及行程線索查閱
- 證據蒐集與數量更新
- 嫌疑人盤問與回應顯示
- 選擇嫌疑人並提交證據
- 依調查結果顯示不同結局
- 使用瀏覽器 `localStorage` 保存部分調查進度（以實際程式功能為準）

## 開發與測試紀錄

本作品採用 Vibe Coding 開發流程，透過與 AI 反覆對話，將原先的戀愛模擬器構想調整為懸疑推理遊戲，再逐步完成網頁功能。

已進行的基本測試：

| 測試項目 | 預期結果 |
|---|---|
| 點擊開始調查 | 成功切換至聊天紀錄 |
| 蒐集證據 | 證據數量正確更新 |
| 盤問嫌疑人 | 顯示對應回應 |
| 提交指控 | 顯示調查結果與結局 |

以上為已執行的基本測試項目；其他線索組合、各種結局與重新遊玩情境，仍可持續測試與改善。
